Night Market

This project focuses on designing a responsive website that motivates a new audience to explore the night market both digitally and physically. It includes three pages in desktop and mobile sizes, with a strong focus on Figma components, layout systems, and accessibility.

Problem

The challenge is to design a visually engaging website while keeping it accessible and easy to use. The design must move beyond typical night market visuals and use a contrasting style, while still maintaining clear hierarchy and readability.
Another problem is ensuring the design works across different screen sizes and supports accessibility such as colour contrast, typography, and clear navigation.

Solution

I designed the website in Figma using reusable components such as navigation bars, cards, buttons, and grids. This creates consistency and improves efficiency when updating designs.
Accessibility was a key focus. I used clear typography, strong hierarchy, and tested colour contrast. The colour palette includes dark blue, rose red, orange, and yellow to create a vibrant night market feeling while maintaining readability.
The layout follows a grid system and mobile-first approach, making the design responsive across devices. Interaction elements like navigation, forms, and filters are designed to be clear and easy to use.

Process

I started with research on design trends and accessibility. Then I created an art direction in Figma, including type scale, colour contrast chart, and grid system.
Next, I built wireframes and high-fidelity designs using Figma components and auto layout, allowing flexible and consistent layouts.
One challenge was balancing bright colours with accessibility, which I solved by adjusting contrast and testing combinations. Another challenge was maintaining consistency across pages, which I improved by using shared components.
The final result includes responsive pages, a clear component system, and accessible UI design.
