Cha Chaan Teng Restaurant Website

Website Design / Branding

--------------------------------------------

A responsive WordPress website for a Cha Chaan Teng (Hong Kong style restaurant).

Built using Divi core modules with a simple brand identity and mobile-first design.

Hong Kong Stlye Restaurant's Website

This project focuses on designing and building a responsive restaurant website using WordPress and Divi. It includes multiple pages such as Home, About, Menu, and Contact/Reservations, with consistent navigation, layout, and branding across all pages.

Problem

This project is based on creating a client-facing retail restaurant website.
The challenge is to design a website that is clean, functional, and fully responsive across desktop, tablet, and mobile. It also requires working within the constraints of WordPress and Divi’s core modules, instead of designing freely without limits.
While designing the website common restaurant content, a clear and easy-to-use layout with a strong visual hierarchy and fast loading performance is needed to maintain.

Solution

I created a simple brand identity using a wordmark with a dark green, which is also the main color of the website. The colour choice is inspired by common HK-style restaurant's interiors and construction materials, giving a stable, natural, and warm feeling.
I used Yrsa as the main font for readability and a more classic, elegant style. I also used the Chinese font Yuji Boku to reflect the cultural identity of a Hong Kong style Cha Chaan Teng.
The design focuses on a clean and modern layout with strong typography and clear hierarchy. The website uses familiar structure and navigation so users can easily find menu, location, and reservation information.
I followed a mobile-first approach with simple layouts to ensure responsiveness. I used Divi’s core modules to build all pages, making sure the design is realistic and responsive. Images are optimized for fast loading, and the layout is consistent across all pages to create a smooth user experience.

Process

I started with a low to mid fidelity Figma mockup to plan the layout, structure, and content hierarchy. I researched existing restaurant websites to understand common UI patterns and user flow.
Then I designed key pages including Home, About, Menu, and Contact, focusing on spacing, typography, and responsive layout. The mockup was kept simple so it could be built using Divi.
During the build phase, I translated the design into WordPress using Divi’s section, row, and column system. One challenge was working within the Box Model and module limitations, which required adjusting layout and simplifying some design ideas.
Another challenge was ensuring responsiveness across different screen sizes, which I solved by testing and adjusting spacing, stacking, and image sizes. The final result is a fully functional website with clear structure, consistent branding, and good usability.
